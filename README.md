# Defect Detection on Textile Fabrics

**Тема ВКР:** Метод обнаружения и локализации дефектов на изображениях текстильных полотен с использованием ИНС.

Модель **DeepLabv3+** с бэкбоном **MobileNetV3**, дополненная модулями:
- координатного внимания;
- слияния пропускных соединений.

Предложенный метод превосходит DeepLabv3+ по значению метрики IoU на 0,91% и точности на 1,17% при снижении полноты на 0,07%. 

Наилучшие значения метрик IoU и точности достигаются, когда дефектные области занимают от 10% до 15% площади всего изображения.
